青禾生活费管家 v2.1 · 便携版
==================================================

一、怎么运行（Windows 10 / 11 64 位）
--------------------------------------------------
1. 把整个文件夹解压到任意位置（路径可以有中文，但不要放在压缩包里直接运行）。
2. 双击 Start.bat。
3. 会自动完成三件事：
   · 启动桌面圆形桌宠（屏幕右下角，始终置顶）
   · 启动本地服务（模拟银行流水 + 托管网页）
   · 打开浏览器 http://localhost:3000

不需要安装 Node.js，包内已经带了 node.exe。
不需要安装 .NET，Windows 10/11 自带 .NET Framework 4.8。

二、目录说明
--------------------------------------------------
Start.bat             一键启动（推荐）
Stop.bat              停止本地服务与桌宠
node.exe              内置 Node.js 运行时（约 93MB）
QinghePet.exe         青禾桌面桌宠（圆形、置顶、可拖动）
website\              网页与模拟流水服务
  index.html          网页入口
  style.css / float.css
  js\                 页面逻辑、网页浮窗、桌宠触发挂件
  simulator\          模拟流水服务 + 百炼 AI 代理
  .env.example        AI Key 配置模板（可选）
README.md             项目原始说明

三、端口说明
--------------------------------------------------
· 默认使用 3000 端口。如果 3000 已被占用（例如队友的模拟流水服务），
  脚本会自动改用 3001 打开网页，网页里的「实时流水演示」仍默认连接
  http://localhost:3000，正好连到队友的服务。
· 如果 3000 被其他程序占用，打开网页后进入「实时流水演示」，
  把服务地址改成 http://localhost:3001 即可。
· 若 3001 也被占用，关闭占用程序后重新双击 Start.bat。

四、桌面桌宠
--------------------------------------------------
· 圆形小猪桌宠，默认在屏幕右下角，覆盖在所有窗口之上。
· 单击：展开完整卡片（余额、进度、建议、近期流水）。
· 拖动：任意位置，靠近边缘自动吸附；位置会被记住。
· 滚轮：桌宠 → 胶囊 → 卡片 循环。
· 右键：总在最前 / 打开网页 / 隐藏金额 / 胶囊模式 /
        回到右下角 / 开机自动启动 / 退出。
· 双击：打开当前网页。
· 网页右下角还有一个小猪挂件，点一下可以重新唤回桌宠，
  并把网页里的预算、已花、剩余天数同步过去。
· 第一次点网页挂件时，浏览器会询问是否允许打开「青禾桌宠」，
  选择“允许”。如果没反应，先手动双击一次 QinghePet.exe。

五、可选：启用阿里云百炼 AI
--------------------------------------------------
便携包不包含任何 API Key。需要 AI 解读 / AI 猜分类时：
1. 把 website\.env.example 复制为 website\.env；
2. 用记事本打开，把 DASHSCOPE_API_KEY= 后面换成自己的百炼 Key；
3. 重新双击 Start.bat。
不配置 Key 时，记账、预算、模拟流水、桌宠等核心功能都能正常使用，
只有 AI 相关按钮会提示未启用。

六、停止
--------------------------------------------------
· 关闭「Qinghe Local Server」命令行窗口，或双击 Stop.bat。
· 桌宠：右键 → 退出；或 Stop.bat。
· 浏览器页面直接关闭即可。

七、常见问题
--------------------------------------------------
1. 浏览器没有自动打开
   手动打开 http://localhost:3000（或 3001）。
2. 页面能打开但实时流水没有数据
   确认「Qinghe Local Server」窗口没有报错；端口是否与网页里的服务地址一致。
3. 桌宠没有出现
   手动双击 QinghePet.exe；若被杀毒软件拦截，请允许运行。
4. 换电脑后网页挂件打不开桌宠
   先手动运行一次 QinghePet.exe，它会自动注册 qinghefloat:// 协议。
5. 端口被占用
   见第三节；或先关闭占用 3000 端口的程序。
6. Windows 防火墙提示
   只监听本机回环地址，选择“允许”即可；不会向互联网开放。

八、数据与隐私
--------------------------------------------------
· 网页数据保存在浏览器 localStorage，不上传。
· 模拟流水是本机生成的演示数据，不连接任何银行。
· 桌宠只监听 127.0.0.1:51888，设置保存在
  %LOCALAPPDATA%\QingheFloat\settings.ini。
· 百炼 API Key 只在本地服务端读取，不会进入网页。

九、拼豆激励机制（v2.2）
--------------------------------------------------
· 月目标按「1–7 / 8–14 / 15–21 / 22–月末」四段拆成周目标。
· 每周花费不超过本周预算即达成，+300 积分；连续达成额外 +50/+100/+150。
· 未达成不扣分，拼豆进度保留；下周正常达成可补签上周 50%（+150）。
· 网页右下角「第 N 周 / 月尺」挂件显示本周剩余和积分，点一下打开桌宠拼豆板。
· 桌宠右键菜单也有「拼豆板 / 本周目标」入口。
· 达成的那一周：自动拼好该区 80%，留 50 颗高识别度细节给你手动拼，每颗 1 积分。
· 4 周拼完整张小猪：熨烫动画，桌宠戴上青色耳机和领带。
· 拼豆板右下角「演示下一周」可在现场快速演示四周节奏。
· 图案文件 bead-pattern.txt 必须和 QinghePet.exe 放在同一目录。
