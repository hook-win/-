# 生活费管家 v2.1 · 实时流水演示版

在 v2(问卷个性化版)基础上新增两大能力:

1. **接入模拟流水程序**:通过 SSE 实时接收模拟银行流水服务推送的交易,自动走三档置信度归类入库;入账自动登记,工资入账提示体验上班族身份。
2. **计时功能(演示时钟)**:每笔流水到达时,系统「当前日期」推进到该笔交易时间;跨月 / 跨年自动切换统计口径并温和提示。流水覆盖 2021 年入学到工作首年,几分钟内即可演示完整大学四年的消费演变。

产品红线不变:授权优先、批量确认不逐笔打扰、未分类池不参与统计与建议、所有数据仅存本机浏览器、不编造任何数字。

## v2.1 提醒用语升级(关怀式个性化)

- **先总结规律,再给建议**:提醒中心新增「小额消费规律」提醒,自动汇总近 30 天(数据不足时自适应放宽到 90 / 180 天并如实标注口径)单笔 ≤¥50 的已定案消费:按分类给出笔数、金额、每周频率、单笔均价、高频商户、深夜时段占比。
- **按类型与频率分档的个性化建议**:餐饮 / 日用 / 交通 / 娱乐 / 学习各有不同话术,同一类型再按频率高低分档——高频不劝戒、只给温和的可选项(「偶尔把一次外卖换成食堂就好,决定权在你」);低频给正向反馈;深夜餐饮额外附一句照顾胃与睡眠的关怀。
- **周累计提醒同步升级**:每周提醒先列「本周小额规律」,再跟一句针对主要消费类型的关怀建议;数据不足的周回落为原有的周对比温和文案。
- 所有规律与建议只从用户已定案的真实记录计算,不编造任何数字;语气始终是关怀而非管控。

## 启动(两种模式)

### 模式 A · 接入队友的模拟流水服务(推荐)

队友的服务运行在 `http://localhost:3000`(251 笔、固定种子)。本目录的 `simulator/server.js` 同时是一个静态服务器,用它托管网页:

```bash
cd website-v2.1
PORT=3001 node simulator/server.js
```

打开 <http://localhost:3001>,进入「实时流水演示」页,勾选授权 → 同意并接入。默认连接 `http://localhost:3000`,跨域已由服务端 CORS 放行。

### 模式 B · 独立演示(队友服务未启动时)

本目录内置了一份按同一接口契约实现的备用模拟流水服务(`simulator/`,零依赖):

```bash
cd website-v2.1
node simulator/server.js
```

打开 <http://localhost:3000> 即可:网页与模拟流水同源托管,一条命令完成接入。端口冲突时用 `PORT=3001` 覆盖。

> 注意:模式 B 的备用数据与队友服务的数据内容不同(商户、金额独立生成),但字段契约与播放行为一致,归类演示效果相同。

## 演示走查脚本

1. 打开页面 → 首页完成八题问卷(或跳过)→ 设定月生活费。
2. 进入「实时流水演示」→ 勾选授权 → 同意并接入。首屏自动补齐最近 5 笔,顶栏出现「演示时间」时钟徽标。
3. 点「继续播放」,速度选 4x:交易逐笔滚入,高置信直接归类、美团/淘宝等攒成批量确认组、大额房租与乱码商户进未分类池。
4. 观察跨月:时钟进入新月份时弹出「本月统计已自动切换」,首页「本月已花 / 日均可用」按演示月份重算;跨年时另有提示。
5. 切到「首页总览」「消费记录」「历史消费记录」:统计、热力图、按月浏览全部跟随演示时钟。
6. 播放到工作首年,工资入账触发关怀提示,可在「身份切换」体验上班族收入规划。
7. 「载入全部历史(训练)」:一次性载入 251 笔,时钟对齐到最后一笔,适合直接展示四年完整画像。
8. 「重置演示」:清空接入记录、时钟恢复真实时间、服务端进度归零重新播放;「恢复真实时间」仅切换时钟口径,不删数据。

## 接入契约

服务端接口与 README(1).md 一致:

| 路径 | 用途 |
|---|---|
| `GET /events` | SSE:`ready`(首屏补齐)/ `transaction`(单笔)/ `status`(播放状态) |
| `GET /player/status` | `{ playing, speed, cursor, total, done }` |
| `POST /player/control` | `{ action: play\|pause\|reset, speed? }`(部分服务端要求 action 必填,客户端已兼容) |
| `GET /transactions/all` | 全部 251 笔,训练数据一键载入 |

字段:`id / time / amount / direction / counterparty / summary / channel / location / locationVisible`。`time` 兼容 `YYYY-MM-DD HH:MM` 与 `YYYY-MM-DD HH:MM:SS` 两种格式;按 `id` 去重,刷新页面、首屏补齐与实时推送不会重复计数。

## AI 能力(阿里云百炼 · 通义千问)

页面多了两个 AI 入口,都走本地代理(`simulator/server.js`),**API Key 只在服务端 `.env` 里,永远不会进浏览器或 localStorage**:

| 位置 | 能力 | 发出去的内容 |
|---|---|---|
| 首页总览「AI 消费解读」 | 把已定案的统计数字组织成三段人话 + 一条零成本小建议,流式打字机输出 | 仅统计数字(分类金额/笔数/预算余量/剩余天数),**不含商户名、不含未分类池明细** |
| 消费记录「未分类池 → AI 猜分类」 | 为低置信商户给出分类建议(chip 上标分类+置信度) | 该笔的商户名、金额、时间 |

产品红线延续:

- AI 结果**不参与**任何预算、日均、提醒与图表计算;归类必须由你点「采纳」才计入统计,否则一直留在未分类池。
- 首次点击会弹一次说明+勾选(存在 `S.aiConsent`),之后不再打扰;撤回授权/重置演示会清空。
- 解读提示词明确约束「只能引用 facts 里的数字、不做除法换算、不说教、不制造焦虑」;服务不可用时卡片与按钮自动降级为提示,其余功能完全不受影响。

### 配置

```bash
cd website-v2.1
# .env(已随项目放置,已被 .gitignore 忽略;换 Key 改这里)
# DASHSCOPE_API_KEY=sk-...
```

### 代理接口

| 路径 | 说明 |
|---|---|
| `GET /api/ai/health` | `{ ok, provider, model, modelClassify, keySource }`,无 Key 时 `ok:false` 且带中文提示 |
| `POST /api/ai/classify` | `{ items:[{id,merchant,amount,time,date}] }` → `{ results:[{id,cat,label,confidence,reason,cached}] }`;最多 40 笔,商户级缓存 |
| `POST /api/ai/advice` | `{ facts:{…} }` → SSE:`data:{"delta":"…"}` 逐字,最后 `event: done` |

来源:`js/ai.js`(前端适配)+ `simulator/ai.js`(百炼客户端)。

## 桌面浮窗（v2.1 适配）

页面右下角新增「生活费浮窗」（`float.js` + `float.css`），读取本地已定案的消费记录，不额外存储任何数据：

- **实时概览**：本月剩余 / 预算进度 / 剩余天数 / 日均可用；有未分类记录时显示「N 笔待确认」。
- **近期流水**：按时间倒序展示最近 8 笔已定案流水，可滚动；单笔 ≥ 预算 12%（最低 ¥200）的行标红为「大额」。
- **两级提醒**：小额超支（≤ 预算 5%，最低 ¥100）用暖色「温馨提示」；大额超支或存在大额支出时用红色「大额警示 / 大额提醒」，点击可定位标红流水。
- **双击打开网页版**：双击浮窗卡片或点工具条里的「网页版」，在新窗口打开消费记录页；新窗口与站内其它页面一样保留浮窗。
- **可操作**：拖动、隐藏金额、刷新、展开分类明细、收起为胶囊；关闭后右下角保留恢复入口。
- **实时联动**：包装了全局 `render()` 并做 2 秒兜底轮询，SSE 实时流水入账、记一笔、跨月切换后浮窗都会自动刷新。
- **移动端**：视口 ≤ 900px 时自动隐藏，避免遮挡底部导航。

## 实现要点

- `js/data.js`:`SIM_TIME` 演示时钟,`nowMs() / simNow()` 统一时间口径;未接入时自动使用真实时间。
- `js/app.js` / `js/views.js`:月统计、剩余天数、热力图、近 N 天、订阅识别等全部改读演示时钟;存储键升级为 `qhb-life-fee-v21`,与 v2 数据互不干扰。
- `js/sim.js`:SSE 接入、去重入库、播放控制、时钟推进与年月切换提示、实时流水视图;授权前不接收任何数据。
- `js/ai.js` / `simulator/ai.js`:百炼适配层与本地代理;`aiFacts()` 只汇总数字,`streamAdvice` 解析 SSE 增量。
- `simulator/`:备用模拟流水服务(固定种子 251 笔 + SSE 播放器 + 静态托管 + AI 代理),Node 内置模块,零依赖。
- 渲染保护:流水到达时若用户正在输入(搜索、表单),只更新时钟徽标,不打断输入。
